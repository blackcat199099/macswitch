MacSwitch — 간단한 설치와 사용법

1. MacSwitch.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 설치한 앱을 실행하고, 화면 오른쪽 위 메뉴 막대의 노트북 아이콘을 누릅니다.
3. 달 = 잠자기 허용 / 해 = 계속 깨어 있기
   닫힌 자물쇠 = 키보드 잠금 / 열린 자물쇠 = 키보드 해제
4. 키보드 잠금은 앱의 '키보드 잠금 권한 설정'을 누른 뒤,
   시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 MacSwitch를 허용합니다.
5. 파란 아이콘과 작은 점이 현재 활성 상태입니다. 마우스를 올리면 설명이 나옵니다.

비상 해제: Esc 키를 1.5초 안에 세 번 누르세요.
잠가도 마우스와 트랙패드는 계속 사용할 수 있습니다.
암호 창이 뜨면 Mac 로그인 암호를 입력해 주세요. 안내는 한국어·영어를 지원합니다.
'잠자기 허용'은 즉시 잠들게 하지 않습니다. 잠자기 설정은 앱 종료 후에도 유지됩니다.
