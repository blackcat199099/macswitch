# 스레드 게시글 초안

복사해 게시할 수 있는 초안입니다. 자동으로 게시하지 않았습니다.

## 본문

맥북 메뉴 막대에서 잠자기와 키보드를 제어하는 작은 앱, MacSwitch를 만들었습니다.

🌙 잠자기 허용 / ☀️ 깨어 있기
🔒 키보드 잠금 / 🔓 해제

켜진 기능은 파란 아이콘으로 표시되고, 마우스를 올리면 설명이 나옵니다. 키보드를 잠가도 마우스와 트랙패드는 쓸 수 있어요.

MIT 라이선스로 소스와 다운로드 파일을 공개했습니다. 한국어·영어 사용법 이미지도 넣었습니다.

첫 실행 때 macOS 실행 허용과 키보드 권한 설정이 필요할 수 있습니다.

https://github.com/blackcat199099/macswitch

## 설치 안내 댓글

다운로드는 저장소 상단의 DMG 링크를 누르시면 됩니다. macOS 14 이상에서 사용할 수 있고, Apple Silicon·Intel 공용입니다.

첫 공개판은 Apple 공증을 받지 않은 앱이라 macOS가 실행을 차단할 수 있습니다. README에 공식 실행 안내와 손쉬운 사용 권한 설정 방법을 적어두었습니다. 잠자기 설정은 앱을 종료해도 유지되니, 다시 허용하려면 달 아이콘을 눌러주세요.

https://github.com/blackcat199099/macswitch/releases/latest
