# MacSwitch v1.0.0

메뉴 막대에서 잠자기와 키보드 입력을 제어하는 첫 공개판입니다.

## 다운로드와 설치

- **MacSwitch.dmg**: 열어서 MacSwitch를 Applications 폴더로 옮기세요.
- **MacSwitch.zip**: 압축을 풀고 앱을 응용 프로그램 폴더로 옮기세요.
- **SHA256SUMS.txt**: 다운로드 파일의 SHA-256 체크섬입니다.
- macOS 14 이상, Apple Silicon·Intel 유니버설 앱입니다. 실제 실행 확인은 Apple Silicon Mac에서 진행했습니다.

달은 잠자기 허용, 해는 깨어 있기, 닫힌 자물쇠는 키보드 잠금, 열린 자물쇠는 해제입니다. 파란색과 작은 점이 활성 상태를 표시합니다. 마우스를 올리면 설명이 나타납니다.

키보드 잠금에는 시스템 설정의 손쉬운 사용 권한이 필요합니다. 마우스와 트랙패드는 계속 사용할 수 있습니다. 비상 해제는 Esc를 1.5초 안에 세 번 누르는 방식이며, 이 조건은 자동 테스트로 확인했습니다. 실제 물리 키보드의 비상 해제 검사는 아직 완료하지 않았습니다. 마우스로 열린 자물쇠를 눌러 해제할 수 있습니다.

첫 배포본은 로컬 서명되어 있으며 Apple Developer ID 서명·공증을 받지 않았습니다. macOS가 실행을 차단할 수 있으므로 [설치 안내](https://github.com/blackcat199099/macswitch/blob/main/README.ko.md)와 [Apple 공식 안내](https://support.apple.com/102445)를 확인하세요. 잠자기 설정 변경 시 macOS 관리자 인증을 요구할 수 있습니다.

한국어·영어 사용법 이미지와 실제 앱 캡처를 포함했습니다. 앱 화면은 현재 한국어입니다. 코드는 MIT 라이선스이며 외부 아이콘의 라이선스·출처 표기는 유지했습니다.

## English

The first public release of MacSwitch adds four menu-bar controls for allowing sleep, staying awake, locking keyboard input, and unlocking it. Blue icons show the current state, with hover descriptions.

Download the DMG and drag the app into Applications, or use the ZIP. The app is universal for Apple Silicon and Intel on macOS 14+. Interactive execution was tested on Apple Silicon; the Intel slice was compiled and structurally verified.

Keyboard locking requires Accessibility permission. Mouse and trackpad input remain available. Triple-Esc recovery is unit-tested; a physical-keyboard end-to-end recovery check is outstanding. Use the open-lock button with the mouse to release the filter.

The build is ad-hoc signed, without Developer ID notarization. See the README for first-launch instructions. macOS handles administrator authentication for sleep changes. The current interface is Korean, with Korean and English illustrated guides included.

Code is MIT-licensed. Third-party icon notices are retained. See `SHA256SUMS.txt` to check downloads and the repository privacy review for publication checks and their scope.
