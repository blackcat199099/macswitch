# MacSwitch v1.0.1

앱 안의 암호 입력 대기 안내를 짧게 바꿨습니다.

**확인된 제한(macOS 27):** “Allow administrator access…”로 시작하는 긴 보안 경고는 macOS가 표시합니다. v1.0.1의 문구 변경으로 이 시스템 경고가 짧아지거나 번역되지는 않습니다. 이전 안내가 실제 적용 범위를 충분히 설명하지 못해 정정합니다.

- 한국어: **Mac 로그인 암호를 입력해 주세요.**
- 영어: **Enter your Mac login password.**
- Mac의 첫 번째 선호 언어가 한국어이면 한국어로, 그 외에는 영어로 표시합니다.
- 앱 안의 암호 입력 대기·취소·실패 안내도 같은 기준으로 정리했습니다.

macOS가 직접 표시하는 버튼과 입력칸 이름은 시스템의 언어 설정을 따릅니다. 암호는 기존처럼 macOS 인증창에서 입력하며 앱이 받거나 저장하지 않습니다. 관리자 계정이 필요할 수 있습니다.

**다운로드:** DMG를 열고 MacSwitch를 Applications 폴더로 옮기세요. ZIP도 제공합니다. macOS 14 이상, Apple Silicon·Intel 공용입니다. 업데이트 뒤 키보드 잠금 권한을 다시 허용해야 할 수 있습니다.

첫 공개판과 마찬가지로 Apple Developer ID 서명·공증은 적용되지 않았습니다. 첫 실행과 권한 설정은 [한국어 안내](https://github.com/blackcat199099/macswitch/blob/main/README.ko.md)를 참고하세요.

## English

Shorter in-app waiting guidance for sleep-setting changes.

**Known limitation on macOS 27:** the system can show a long “Allow administrator access…” script-security warning instead of the requested short prompt. v1.0.1 does not shorten or translate that system warning. Earlier notes overstated the scope of this copy change.

- Korean: **Mac 로그인 암호를 입력해 주세요.**
- English: **Enter your Mac login password.**

Korean is used when it is the Mac’s first preferred language; other languages use English. Related waiting, cancellation, and failure messages use the same language choice.

macOS-owned dialog buttons and field labels follow the system language. Credentials are entered into the existing macOS authorization dialog; the app does not receive or store them. An administrator account may be required.

Download the universal DMG or ZIP for macOS 14+. This update is ad-hoc signed without Developer ID notarization; Accessibility permission may need to be granted again after updating.

See the README and verification notes for installation steps and existing platform-testing limits.
